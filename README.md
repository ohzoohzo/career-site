# 커리어 길잡이 (career-site)

조원 수만큼 메뉴가 있는 취업 준비 사이트입니다. 개발·디자인·PO·마케팅 취업 준비생을 돕습니다. 한 사람이 한 페이지를 맡아 Claude Code로 만듭니다.

## 작업 분담

| 메뉴 | 폴더 | 담당 |
|---|---|---|
| 홈 | `index.html` | 여원 |
| 직무 사전 | `roles/` | 선이 |
| 채용 공고 | `jobs/` | 명근 |
| 자주 묻는 질문 | `faq/` | 현경 |

## 규칙

- 공통 규칙은 맨 위 `CLAUDE.md`, 페이지 규칙은 각 페이지 폴더의 `CLAUDE.md`에 씁니다.
- 공통 규칙과 페이지 규칙이 부딪히면 **공통 규칙이 이깁니다.**
- `style.css`와 `_틀.html`은 디자인 담당 1명만 고칩니다.
- 다른 사람 폴더는 고치지 않고 담당자에게 말합니다.
- 합친 뒤 `/check-site`로 사이트 전체를 점검합니다.
