- 메뉴: 자주 묻는 질문 · 파일 `faq/index.html` · 담당 현경
- 참고 이미지
  - **구조(레이아웃)**: `image.jpg` — 검색창 → 왼쪽 분류 목록 + 오른쪽 질문 아코디언 → "아직 궁금한 게 있나요?" 안내 상자
  - **디자인(분위기)**: `faq.png` — 크림색 종이 바탕, 파스텔 포스트잇, 마스킹 테이프, 손글씨 느낌의 물음표, 남색 글자, 빨간 나침반 로고

## 1. 왜 만드나요

취업 준비생이 혼자 끙끙 앓는 질문을 한곳에 모아, **검색 한 번·클릭 한 번**으로 답을 찾게 합니다.
"나만 이런 고민을 하는 게 아니구나" 하는 안심과 다음 행동(직무 사전 보기, 공고 보기)까지 이어 주는 것이 목표예요.

| 누가 | 무엇이 궁금한가 |
|---|---|
| 직무를 아직 못 정한 사람 | 무엇부터 해야 하는지, 전공과 달라도 되는지 |
| 서류를 쓰는 사람 | 이력서·자기소개서·포트폴리오를 어떻게 채울지 |
| 면접을 앞둔 사람 | 자주 나오는 질문과 과제, 준비 방법 |
| 지친 사람 | 불합격·비교·공백기에 대한 마음 관리 |

## 2. 레이아웃 (image.jpg 구조를 따름)

```
┌─────────────────────────────────────────────────────┐
│ [로고] 커리어 길잡이        [홈][직무 사전][채용 공고][자주 묻는 질문] │  ← 공통 헤더 (폴더 탭)
├─────────────────────────────────────────────────────┤
│ 자주 묻는 질문                                          │  ← 제목 + 한 줄 소개
│ 혼자 고민하지 말고, 궁금한 마음을 꺼내 보세요.              │
│ [🔍 궁금한 낱말을 적어 보세요.                     ✕]  │  ← 검색창 (입력 즉시 걸러짐)
│ (모두)(직무 고민)(서류 준비)(면접)(마음 관리)            │  ← 주제 칩
├──────────┬──────────────────────────────────────────┤
│ 직군      │  ┌ 테이프 ┐                                │
│ ▸ 전체 32 │  [?] 개발 · 면접                       [+] │  ← 포스트잇 아코디언
│   공통 12 │      코딩 테스트는 어느 정도 …              │
│   개발  5 │  [?] …                                  [−] │
│   디자인 5 │      답변 …                               │
│   PO    5 │  …                                        │
│   마케팅 5 │                                           │
├──────────┴──────────────────────────────────────────┤
│  아직 궁금한 게 남았나요?          [질문 상자 그림]       │  ← 질문 넣기 안내 상자
│  [질문 넣기]                                           │
├─────────────────────────────────────────────────────┤
│ [로고] 커리어 길잡이         지금도, 더 나은 내일을 …     │  ← 공통 푸터
└─────────────────────────────────────────────────────┘
```

| 영역 | image.jpg에서 가져온 것 | 우리 사이트에 맞게 바꾼 것 |
|---|---|---|
| 검색창 | 가운데 큰 검색창 | 글자를 칠 때마다 바로 걸러짐, 찾은 낱말은 형광펜 표시 |
| 왼쪽 분류 | 카테고리 세로 목록 | **직군**(전체·공통·개발·디자인·PO·마케팅) + 개수 표시 |
| 질문 목록 | 흰 카드 아코디언 + `+` | 주제 색 포스트잇 + 테이프, 열리면 `−` |
| 아래 안내 | Still have questions? | "아직 궁금한 게 남았나요?" + 질문 상자 |

필터는 두 겹입니다: **직군(왼쪽)** × **주제(위 칩)** × **검색어**. 세 가지가 동시에 적용돼요.

### 반응형

| 폭 | 모양 |
|---|---|
| 860px 이상 | 왼쪽 분류(220px, 스크롤해도 따라옴) + 오른쪽 목록 2단 |
| 860px 미만 | 분류가 목록 위로 올라가 칩처럼 줄바꿈 |
| 375px | 메뉴 탭 4개 한 줄, 질문 아이콘 축소, 가로 스크롤 없음 |

## 3. 디자인 (faq.png 분위기를 따름)

### 색 (모두 `var(--…)`로만 사용)

| 변수 | 용도 | 값(임시) |
|---|---|---|
| `--bg` | 페이지 바탕(크림) | `#faf7f0` |
| `--paper` | 게시판·사이드 바탕(종이) | `#f1ece0` |
| `--surface` | 밝은 면(검색창, 선택된 항목) | `#fffdf8` |
| `--ink` | 제목·본문 남색 | `#1c2a52` |
| `--ink-soft` | 보조 글자 | `#4b5574` |
| `--line` | 선 | `#d8d2c3` |
| `--accent` | 로고·버튼 빨강 | `#d43c3c` |
| `--note-yellow/green/pink/blue` | 포스트잇 4색 | 파스텔 |
| `--tape-*` | 마스킹 테이프 | 반투명 파스텔 |

> 공통 `style.css`가 아직 폴더에 없어서, `faq.css` 맨 위에 **임시 변수 묶음**을 두었습니다.
> 공통 파일 담당이 `style.css`에 변수를 만들면, 이름을 맞추고 임시 묶음은 지웁니다.

### 주제 = 포스트잇 색

| 주제 | 색 | 이유 |
|---|---|---|
| 직무 고민 | 노랑 | 생각을 정리하는 메모 |
| 서류 준비 | 초록 | 차근차근 쌓아 가는 일 |
| 면접 | 분홍 | 두근거리는 순간 |
| 마음 관리 | 파랑 | 차분하게 쉬어 가기 |

### 컴포넌트

- **헤더 메뉴**: 서류철 탭 모양. 현재 페이지 탭만 바탕색과 이어지고 굵게 (`aria-current="page"`).
- **포스트잇 질문**: 살짝 기울어진(±0.4°) 카드, 위에 테이프, 왼쪽에 테두리만 있는 큰 `?`, 오른쪽 `+/−`. 마우스를 올리면 반듯해지며 살짝 떠오름. 움직임 줄이기 설정이면 기울기·애니메이션 없음.
- **답변**: 질문 아래 얇은 점선으로 나누고, 필요하면 "직무 사전 보러 가기" 같은 다음 행동 링크.
- **질문 상자**: 선으로 그린 상자 그림(SVG) + "질문 넣기" 버튼 → 작은 창에서 직군 고르고 질문 적기.
- **글꼴**: 외부 폰트를 새로 넣지 않으므로 기기 기본 한글 글꼴(맑은 고딕, Apple SD Gothic Neo).

## 4. 기능

| 기능 | 동작 |
|---|---|
| 검색 | 질문·답변·직군·주제 이름에서 찾음. 대소문자 무시. 찾은 낱말 `<mark>` 표시. `✕`로 지우기 |
| 직군 필터 | 왼쪽 목록 클릭. 각 직군 옆 숫자는 현재 주제·검색어 기준 개수 |
| 주제 필터 | 칩 클릭. "모두"로 되돌리기 |
| 아코디언 | 여러 개 동시에 열 수 있음. 첫 질문은 처음부터 열림 |
| 결과 안내 | "질문 N개" 를 화면 읽기 프로그램에도 알려 줌(`aria-live`) |
| 결과 없음 | "찾는 질문이 없어요" + 조건 초기화 버튼 + 질문 넣기 안내 |
| 주소로 바로 열기 | `faq/index.html#dev` 처럼 열면 해당 직군이 골라진 상태 (직무 사전에서 링크 걸 때 사용) |
| 질문 넣기 | 서버가 없으므로 **이 브라우저에만 저장**(연습용)되고, 그 사실을 창에 적어 둠 |

`fetch`는 쓰지 않습니다. 질문 데이터는 `faq.js` 안에 배열로 들어 있어요.

## 6. 접근성 체크

- 질문 버튼은 `<button aria-expanded aria-controls>` — Tab·Enter·Space로 열고 닫기
- 직군·주제 버튼은 `aria-pressed`로 선택 상태 전달
- 모든 그림(로고, 질문 상자)은 `alt`/`aria-label` 또는 장식용이면 `aria-hidden`
- 키보드 초점이 잘 보이도록 `:focus-visible` 테두리
- 본문 바로가기 링크
